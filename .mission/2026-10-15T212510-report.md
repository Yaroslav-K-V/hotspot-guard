  animated mouse cursor.

## What landed

- `DemoWiFiController` (shot-only fake in `ShotRunner.swift`, `#if DEBUG`):
  fixed neutral SSID "Home Wi-Fi", association always throws before
  touching hardware. Shot `AppModel` uses it instead of the real
  `CoreWLANController`, so no render ever leaks the machine's real
  network name (menu header, samples, History rows).
- `AppModel` gains defaulted `wifi:` and `notifier:` injection params;
  production call site unchanged (`CoreWLANController`,
  `UserNotificationPresenter`).
- Shot frames 8 → 14; new `SilentNotifier` so an offline render can never
  banner Notification Center; scratch suite cleared + store reset each
  run for deterministic re-runs.
- New `scripts/make-demo-gif.sh` (documented in AGENTS.md): 12-frame
  guard, ffmpeg/Pillow preflights, pad + rounded corners, animated
  cursor along waypoints, crossfaded 12fps output (53 frames, ~4.5 s
  loop, ~2 MB), palette-optimised GIF.
- `docs/demo-menu.gif` regenerated (14 source frames, neutral SSIDs,
  cursor); `docs/demo-history.png` refreshed.
- Follow-up: interpolated motion (background crossfade + fractional
  cursor positions) for smoothness.
