# Demo GIF v2 brief — feature/demo-gif

## Task 1: Neutral demo network, longer GIF, mouse cursor

Goal: the README demo GIF shows no real user location (replace Campus90
with a neutral SSID), runs longer (12+ frames), and animates a mouse
cursor over the UI.

### Steps

1. Add a shot-only fake Wi-Fi controller (`DemoWiFiController`, in
   `ShotRunner.swift`, `#if DEBUG`) returning a fixed neutral SSID and
   use it for the shot `AppModel` instead of the real
   `CoreWLANController`, so neither the menu header, samples, History
   rows nor CSV/JSON ever see the machine's real network name.
2. Raise menu frames 8 → 14 in `ShotRunner.run`.
3. Add `scripts/make-demo-gif.sh` (documented in AGENTS.md Commands):
   pad frames to a uniform canvas with the panel colour, round corners,
   draw an animated cursor visiting UI hotspots across frames (PIL),
   assemble palette-optimised GIF via ffmpeg (fail loudly if ffmpeg or
   frames are missing).
4. Regenerate `docs/demo-menu.gif` (+ keep `docs/demo-history.png`),
   verify no real SSID is visible in any frame.
5. Run the full gate: `swift build`, `swift build -c release`,
   `swift run hotspotguard-selftest`, `format.sh --check`, `lint.sh`
   (0 serious), `dead-code.sh`, `check-test-layout.sh`, `duplicates.sh`,
   `coverage.sh`, `generate-api-docs.sh --check`, `check-agents-md.sh`,
   `flaky-check.sh`.

### Reachability targets (must fail before, pass after)

- `test "$(python3 -c "from PIL import Image; print(Image.open('docs/demo-menu.gif').n_frames)")" -ge 12`
- `grep -q "DemoWiFi" Sources/HotspotGuard/ShotRunner.swift`
- `grep -qi "cursor" scripts/make-demo-gif.sh`

### Constraints

- No push, no PR, no force-push, no deletion, no payments, no credentials.
  Local branch only.
- Shot mode must stay side-effect free: temp UserDefaults suite, temp
  analytics dir, no bootstrap, no Keychain writes, no real SSID anywhere.
- Everything on-device: no network calls beyond the live probe ticks the
  shots already perform, no new hosts, no dependencies.
